# dotnet-mvc-starter

Minimal ASP.NET MVC 5 web application with Entity Framework and Bootstrap theming.

## Features

- MVC routing and controllers
- Entity Framework Code First
- Bootstrap responsive layout
- NuGet package management

## Getting Started

1. Open `dotnet-mvc-starter.sln` in Visual Studio
2. Restore NuGet packages
3. Press F5 to run
